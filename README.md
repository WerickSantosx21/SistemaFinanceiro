# DevFinance

Sistema de controle financeiro simples desenvolvido com:

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Funcionalidades

- Adicionar receitas
- Adicionar despesas
- Listar transações
- Excluir transações

## Como rodar o projeto

Clone o repositório

git clone

Instale dependências

pip install -r requirements.txt

Execute

python app.py
